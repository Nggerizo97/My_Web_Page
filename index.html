    I'm a Software & Cloud Data Engineer with 4+ years in banking and energy (Scotiabank, Bancolombia, ISA). I build data pipelines and backend services, and I take care of the delivery side too: CI/CD, containers, infrastructure as code and automated testing.


    I trained as a mechatronics engineer with a focus on robotics and computer vision. That background moved into data analytics, then software and cloud engineering, and it left me with the habit of thinking about the whole system instead of one piece.


    Right now I'm a Full-Stack Software Engineer at Scotiabank, contributing to the migration of Spring Boot services from on-premises to Google Cloud, with Microsoft Entra ID sign-in and API-to-API calls secured by scope-based signed JWTs. Before that I helped cut Bancolombia's production deployments from 48 hours to 2 with Azure DevOps.


    Outside work I run Real Estate Analyst Colombia: scheduled GitHub Actions scrapers, a PySpark medallion lakehouse on Databricks and S3, an XGBoost valuation model and a Streamlit app, for under US$1 a month.


    Open to software, cloud data and DevOps engineering roles, remote.
